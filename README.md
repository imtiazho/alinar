# Alinar — Fashion E-commerce Platform

Alinar is a full-stack fashion e-commerce platform designed for browsing products, viewing product details, managing user accounts, and handling orders.

This repository contains the **frontend application** built with React.

## ✨ Features

* Browse fashion products
* View product details
* Category-based product browsing
* User account management
* Shopping/order workflow
* Protected user features
* Admin/moderator management interface
* Responsive user interface
* Backend API integration

## 🛠️ Technologies

* React.js
* JavaScript
* React Router
* CSS
* REST API
* JWT Authentication

## 🏗️ Project Structure

The project is organized as a React frontend application that communicates with a separate Node.js/Express backend through REST APIs.

```text
Alinar
├── Frontend
│   ├── React.js
│   ├── Components
│   ├── Pages
│   └── API Integration
│
└── Backend
    ├── Node.js
    ├── Express.js
    ├── MongoDB
    └── JWT Authentication
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/imtiazho/alinar.git
cd alinar
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

The application will run locally according to the configured development environment.

## 📌 About the Project

Alinar was built as a practical full-stack e-commerce project to understand how a React frontend communicates with a backend API and database.

The project helped me practice product management, authentication, protected operations, user management, and order-related workflows while working with a separate frontend and backend architecture.
